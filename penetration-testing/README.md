# Penetration Testing

Basic penetration testing process:

```text
Reconnaissance
      |
Enumeration
      |
Vulnerability Identification
      |
Exploitation
      |
Post-Exploitation
      |
Reporting
```

## Topics

- Reconnaissance
- Enumeration
- Vulnerability identification
- Exploitation
- Post-exploitation
- Reporting

One thing I learned is that a penetration test is not just about exploiting a vulnerability. The findings also need to be validated, documented and explained clearly.
